# 📊 Descriptive-Stats-Viz 🚀

---

## ✨ Project Goals
- 📈 Display raw data alongside statistical metrics on a single plot  
- 🧮 Facilitate understanding of basic statistical concepts (mean, median, mode, variance, standard deviation, etc.)  
- 🎓 Provide an educational tool for statistics and data science classes  
- 🔮 Create a foundation for future development with advanced statistical measures  

---

## ⚡ Features
- ✅ Calculates and displays:
  - 📍 Mean  
  - 📍 Median  
  - 📍 Mode  
  - 📍 Variance  
  - 📍 Standard Deviation  
  - 📍 Range  
  - 📍 Quartiles  
  - 📍 Percentiles  
  - 📍 Interquartile Range (IQR)  
- 🎨 Draws statistical lines with different colors on the line plot  
- 📝 Text annotations for each metric for clarity  
- 🛠️ Built with popular libraries: `matplotlib`, `numpy`, `scipy`
